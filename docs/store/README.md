# Store listing drafts

Drafts for the first Google Play (closed testing / alpha) and App Store
Connect (TestFlight) setup. Used by [`docs/RELEASE_CHECKLIST.md`](../RELEASE_CHECKLIST.md).
Replace `{{DEVELOPER_NAME}}` and `{{CONTACT_EMAIL}}` before pasting anything.

| File | Where it goes |
|---|---|
| [play-listing.md](play-listing.md) | Play Console → Main store listing, App access, alpha release notes |
| [app-store-listing.md](app-store-listing.md) | App Store Connect → version page, App Information, TestFlight "What to Test" |
| [play-data-safety.md](play-data-safety.md) | Play Console → App content → Data safety, Advertising ID, Ads |
| [app-store-privacy.md](app-store-privacy.md) | App Store Connect → App Privacy |
| [content-rating.md](content-rating.md) | Play IARC questionnaire, Target audience; App Store age rating |
| [export-compliance.md](export-compliance.md) | TestFlight export compliance / `ITSAppUsesNonExemptEncryption` |

The privacy policy draft is [`confirm-pages/privacy.html`](../../confirm-pages/privacy.html).
Keep these files in step with it when the app's data use changes (new SDK,
new synced field, analytics, etc.).
